# Haider Imran — Portfolio

A redesigned personal portfolio for Haider Imran, combining a clean minimal interface with a dark, premium developer aesthetic.

## Included

- `index.html` — portfolio page
- `style.css` — responsive styling and visual system
- `script.js` — lightweight scroll-reveal animation

## Deploy with GitHub Pages

1. Replace the files in your existing `My-Portfolio` repository with these three files.
2. Commit and push to the branch currently used by GitHub Pages.
3. Open your existing portfolio URL:
   `https://haiderimran019.github.io/My-Portfolio/`

No build step or framework is required.

## Before publishing

Update any details you want to personalize further, especially:
- Current skills
- Current learning list
- Project descriptions
- LinkedIn URL
- Contact email, if needed

The project links currently point to the public repositories and demos already associated with the portfolio.
